# Meesho Clone 🛍️

A simple front-end clone of the Meesho website built using HTML and CSS.

## 🌟 Features

* Clean and user-friendly interface
* Product navigation layout
* Category section
* Product display section
* Responsive styling

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📸 About the Project

This project is inspired by the Meesho e-commerce platform. It focuses on recreating the website's layout and design using basic front-end technologies.

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
